# DewMinas
이력서 템플릿 공유 웹 사이트 듀미나스(DewMinas)

제공 기능 : 이력서 관리(등록, 수정, 삭제, 조회), 프로젝트 관리(등록, 수정, 삭제, 조회), 템플릿 생성 기능
캡스톤 디자인(2024-2)

server : springboot3, java, thymeleaf
client : js(vanilla), html, css
